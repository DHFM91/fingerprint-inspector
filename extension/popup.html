WebRTC IP leak test

Checks what IP addresses WebRTC reveals. Useful with a VPN on: if your real public IP shows up here while the VPN is on, sites can see it too. This contacts Google's public STUN server, so it only runs when you click.

Save snapshots in different situations (other browsers, private windows, VPN on/off, privacy settings), then tick two to see exactly what changed.
